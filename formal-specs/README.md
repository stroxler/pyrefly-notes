# Formal specifications

Implementation-independent models and specifications for Python domains relevant to
Pyrefly development. Each project lives in its own subdirectory.

- [Python project structure](project-structure/): storage, packaging, import and typing
  structure, analysis context, and their evolution.

Specifications distinguish guarantees from Python and packaging references, explicit
tooling policies, and observations of particular implementations. Implementation
behavior and issue reports are evidence to investigate, not the definition of the
domain.
